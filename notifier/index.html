Notifier

Σταμάτα να κάνεις refresh στο eClass. Ο Notifier ελέγχει για σένα ανακοινώσεις, εργασίες, εργαστήρια και βαθμούς, και σε ειδοποιεί στο κινητό.

Λήψη για Mac Λήψη για Windows Κώδικας στο GitHub →

Πώς δουλεύει

  1. 01

    Κατέβασε την εφαρμογή

    Για Mac ή Windows. Στο Mac σύρε την στο /Applications και άνοιξέ την με δεξί κλικ → Άνοιγμα την πρώτη φορά.

  2. 02

    Διάλεξε πανεπιστήμιο και συνδέσου

    Η σύνδεση ελέγχεται στη στιγμή. Οι κωδικοί μπαίνουν στο Keychain ή στο Credential Manager, όχι σε αρχείο.

  3. 03

    Πάρε ειδοποιήσεις

    Στο κινητό μέσω ntfy (σκανάρεις ένα QR) ή στον υπολογιστή. Οι έλεγχοι τρέχουν αθόρυβα στο παρασκήνιο.

Τι ελέγχει, και πότε

Οι ώρες είναι προεπιλογές και αλλάζουν από ένα αρχείο ρυθμίσεων.

Το πρόγραμμα δεν ξέρει τίποτα.

  • Οι κωδικοί σου ζουν μόνο στα GitHub Secrets του δικού σου repo.
  • Ό,τι έχει δει αποθηκεύεται κρυπτογραφημένο με AES-256-GCM.
  • Logs με μόνο αριθμούς. Push και email χωρίς περιεχόμενο σε ιδιωτική λειτουργία.
  • Κανένας server τρίτου. Ούτε δικός μου.

Για developers

Ο κώδικας είναι ανοιχτός (MIT). Το dry run δείχνει τι θα σου έστελνε, χωρίς να στείλει τίποτα.

# κώδικας
git clone https://github.com/Fragkiskospall/notifier
pip install -e ".[launcher]"

# ο launcher
fragkiskosource-notifier

# τι θα έστελνε τώρα;
python -m uniwa_notifier digest --dry-run
