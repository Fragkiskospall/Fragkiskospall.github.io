Notifier

Σταμάτα να κάνεις refresh στο eClass. Ο Notifier ελέγχει για σένα ανακοινώσεις, εργασίες, εργαστήρια και βαθμούς, και σε ειδοποιεί στο κινητό.

Repo: σύντομα στο GitHub

Πώς δουλεύει

  1. 01

    Φτιάξε το δικό σου αντίγραφο

    Από το template δημιουργείς ένα private repo στον λογαριασμό σου. Κανείς άλλος δεν το βλέπει.

  2. 02

    Τρέξε τον οδηγό ρύθμισης

    Διαλέγεις πανεπιστήμιο και τμήμα. Οι κωδικοί σου μπαίνουν κατευθείαν στα GitHub Secrets.

  3. 03

    Πάρε ειδοποιήσεις

    Push μέσω ntfy, email ή ειδοποίηση macOS. Τρέχει στο GitHub Actions, χωρίς να μένει ανοιχτός ο υπολογιστής σου.

Τι ελέγχει, και πότε

Οι ώρες είναι προεπιλογές και αλλάζουν από ένα αρχείο ρυθμίσεων.

Το πρόγραμμα δεν ξέρει τίποτα.

  • Οι κωδικοί σου ζουν μόνο στα GitHub Secrets του δικού σου repo.
  • Ό,τι έχει δει αποθηκεύεται κρυπτογραφημένο με AES-256-GCM.
  • Logs με μόνο αριθμούς. Push και email χωρίς περιεχόμενο σε ιδιωτική λειτουργία.
  • Κανένας server τρίτου. Ούτε δικός μου.

Δοκίμασέ το τοπικά

Το dry run δείχνει τι θα σου έστελνε, χωρίς να στείλει τίποτα.

# εγκατάσταση
pip install -e .

# κωδικοί στο Keychain, όχι σε αρχείο
python -m notifier secrets set ECLASS_USERNAME

# τι θα έστελνε τώρα;
python -m notifier digest --dry-run
