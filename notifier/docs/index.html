Πώς δουλεύει

Ελέγχει, συγκρίνει, ειδοποιεί. Όλα στον υπολογιστή σου.

Η μεγάλη εικόνα

Ο Notifier ελέγχει σε τακτά διαστήματα το Open eClass, το RSS του τμήματος και την πύλη φοιτητών. Συγκρίνει ό,τι βρήκε με όσα έχει ήδη δει και σε ειδοποιεί μόνο για τα καινούργια. Δεν υπάρχει server.

 ┌──────────────────────────── ο υπολογιστής σου ────────────────────────────┐
 │                                                                           │
 │  ┌────────────┐   εγκαθιστά    ┌──────────────────────────────────────┐  │
 │  │  Launcher  │ ─────────────▶ │  Χρονοπρογραμματιστής λειτουργικού   │  │
 │  │ (PySide6)  │                │  macOS: launchd (LaunchAgents)       │  │

 │  │ Keychain /         │ ◀──── κωδικοί ────┐       ▼                       │
 │  │ Credential Manager │                   │  ┌──────────────────────┐    │
 │  └────────────────────┘                   └──│  Job                 │    │
 │                                              │  check · grades      │    │
 │  ┌────────────────────┐   seen.db.enc        │  digest · labs       │    │
 │  │ state/ (AES-GCM)   │ ◀──────────────────▶ └──────────┬───────────┘    │
 │  └────────────────────┘                                 │                │
 └─────────────────────────────────────────────────────────┼────────────────┘
                                                           │ HTTPS
              ┌──────────────────────┬─────────────────────┼──────────────┐
              ▼                      ▼                     ▼              ▼
        Open eClass            RSS τμήματος          Πύλη φοιτητών     ntfy / SMTP
     (ανακοινώσεις,                                   (βαθμοί)        (ειδοποιήσεις)
      εργασίες, ομάδες)

Ένα εκτελέσιμο κάνει δύο δουλειές. Χωρίς ορίσματα ανοίγει τον launcher, το παράθυρο ρυθμίσεων. Με όρισμα (check, grades, digest, labs) τρέχει ένα job χωρίς παράθυρο και κλείνει. Ο χρονοπρογραμματιστής του λειτουργικού το καλεί με το σωστό όρισμα, οπότε η εφαρμογή δεν μένει ανοιχτή στο παρασκήνιο.

Τα jobs

checkΚάθε 30 λεπτά. Νέες ανακοινώσεις από τα μαθήματα του eClass και από το RSS του τμήματος.
gradesΚάθε 30 λεπτά. Νέοι ή αλλαγμένοι βαθμοί στην πύλη φοιτητών, όπου υποστηρίζεται.
digest08:00, 14:00, 21:00. Σύνοψη εργασιών με προθεσμίες, από την πιο κοντινή.
labsΜε την πρώτη σύνοψη της ημέρας. Υπενθύμιση για τα εργαστήρια της ημέρας, από τις ομάδες χρηστών του eClass.

Τα ωράρια αλλάζουν από τον launcher.

Ένας κύκλος ελέγχου

Παράδειγμα με το check:

  launchd / Task Scheduler
          │
          ▼
  1. Φόρτωση ρυθμίσεων ─────── config.toml + κατάλογος πανεπιστημίων
          │                    (eclass_url, RSS τμήματος, πύλη)
          ▼
  2. Κωδικοί ─────────────── Keychain / Credential Manager
          │
          ▼
  3. Άνοιγμα state ────────── seen.db.enc ──αποκρυπτογράφηση──▶ προσωρινό seen.db
          │
          ▼
  4. Συλλογή ─────────────── login στο eClass, λίστα μαθημάτων,
          │                  ανακοινώσεις κάθε μαθήματος (RSS ή HTML),
          │                  RSS τμήματος
          ▼
  5. Σύγκριση ────────────── κρατά μόνο ό,τι δεν έχει ξαναδεί
          │
          ├── τίποτα νέο ──▶ τέλος
          ▼
  6. Ειδοποίηση ──────────── desktop · ntfy · email
          │
          ▼
  7. Αποθήκευση ──────────── κρυπτογράφηση → seen.db.enc
                             το προσωρινό αρχείο σβήνεται

Αν αποτύχει η αποστολή, τίποτα δεν σημειώνεται ως ειδωμένο και ξαναδοκιμάζεται στον επόμενο κύκλο.

Τι είναι «νέο»

Κάθε στοιχείο έχει σταθερό αναγνωριστικό, που γράφεται σε μια μικρή βάση SQLite όταν το δει.

Ανακοίνωση eClasseclass:<μάθημα>:<an_id>
RSS τμήματοςdept:<guid ή link>
ΒαθμόςΜάθημα και εξεταστική, μαζί με την προηγούμενη τιμή.

Την πρώτη φορά που εμφανίζεται μια πηγή, για παράδειγμα ένα νέο μάθημα, οι υπάρχουσες ανακοινώσεις της καταγράφονται χωρίς ειδοποίηση. Έτσι η πρώτη εκτέλεση δεν σου στέλνει διακόσιες παλιές ανακοινώσεις.

Πανεπιστήμια

Κάθε ίδρυμα είναι ένα αρχείο TOML στον κατάλογο. Από εκεί η εφαρμογή παίρνει τη διεύθυνση του Open eClass, τα RSS των τμημάτων και, όπου υποστηρίζεται, την πύλη φοιτητών. Στις ρυθμίσεις αρκεί:

[university]
id = "uniwa"
department = "ice"

Για να προσθέσεις ίδρυμα, δες τον οδηγό στο GitHub.

Απόρρητο

  Κωδικοί πανεπιστημίου ──▶ Keychain (Mac) / Credential Manager (Windows)
  Κλειδί κρυπτογράφησης  ──▶ Keychain / Credential Manager
  Ιστορικό               ──▶ state/seen.db.enc     AES-256-GCM
  Τελευταίες εκτελέσεις  ──▶ logs/runs.json        μόνο ώρα και αποτέλεσμα
  • Η βάση σε απλή μορφή υπάρχει μόνο σε προσωρινό φάκελο όσο τρέχει ένα job.
  • Αν χαθεί το κλειδί, το ιστορικό ξαναχτίζεται από την αρχή, χωρίς ειδοποιήσεις.
  • Στην ιδιωτική λειτουργία, το κινητό και το email λένε μόνο «3 νέες ανακοινώσεις», χωρίς τίτλους, μαθήματα ή βαθμούς.
  • Η «Διαγραφή όλων» στον launcher σβήνει jobs, κωδικούς, ρυθμίσεις και ιστορικό.

Ειδοποιήσεις

ΥπολογιστήςΕιδοποίηση του λειτουργικού, μία ανά στοιχείο, με link.
ntfyPush στο κινητό μέσω ntfy.sh ή δικού σου server. Το topic το διαλέγεις εσύ.
EmailΜέσω SMTP, σε απλό κείμενο και HTML.

Ανά λειτουργικό

macOSLaunchAgents και Keychain. Το app πρέπει να είναι στο /Applications, όχι σε Desktop, Documents ή Downloads.
WindowsΚρυφά tasks στο Task Scheduler, που τρέχουν και όταν ο υπολογιστής ξυπνήσει, και Credential Manager. Χωρίς παράθυρο κονσόλας.

Δομή κώδικα

src/uniwa_notifier/
├── cli.py            σημείο εισόδου: launcher ή job
├── config.py         ρυθμίσεις + κατάλογος
├── catalog/          ένα TOML ανά πανεπιστήμιο
├── eclass/           login και ανάγνωση σελίδων Open eClass
├── services/         πύλη φοιτητών (βαθμοί)
├── feeds.py          RSS / Atom
├── jobs/             announcements · grades · digest · labs
├── notify/           desktop · ntfy · email
├── state.py          τι έχουμε δει
├── vault.py          κρυπτογράφηση του state
├── secrets.py        Keychain / Credential Manager
├── system/           macOS · Windows · Linux
└── launcher/         οθόνες PySide6 και εγκατάσταση

Γραμμή εντολών

python -m uniwa_notifier check --dry-run -v   # τι θα έστελνε, χωρίς αποστολή
python -m uniwa_notifier digest --dry-run
python -m uniwa_notifier grades
python -m uniwa_notifier labs

Με --dry-run δεν στέλνεται τίποτα και δεν αλλάζει το ιστορικό.

Build και releases

Σε κάθε pull request τρέχουν τα tests σε Linux, Windows και macOS. Όταν μπει tag έκδοσης, το GitHub Actions χτίζει το .app και το .exe από τον ίδιο κώδικα και τα ανεβάζει στα Releases.
